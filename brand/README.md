# x207 brand

| File | Use |
| --- | --- |
| `x207-logo-light.svg`, `x207-logo-dark.svg` | Icon and wordmark, on light or dark backgrounds |
| `x207-wordmark-light.svg`, `x207-wordmark-dark.svg` | Wordmark only |
| `x207-icon-light.svg`, `x207-icon-dark.svg` | Icon only, 32px and larger |
| `x207-favicon.svg` | Heavier icon for 16px to 24px, follows the system color scheme |
| `x207-avatar.svg`, `x207-avatar.png` | Square icon on white, for profile images |

Use the wordmark at 24px tall or larger. Below that, use the icon.

Colors: ink `#2C2C2A` and teal `#0F6E56` on light backgrounds, ink `#F1EFE8` and teal `#5DCAA5` on dark backgrounds.

The icon shows a circle of three parties with obligations cleared at its center. All shapes are SVG paths and need no font.
