# Optional NEAR resources for the roadmap (evaluation)

Status: an evaluation, not a plan. Each resource has a decision, the feature it would touch and a rough effort in days of one developer. Sources were read on 2026-11-02; what could not be read is marked "not verified". Effort figures are my estimates, not measurements.

| Resource | Decision | Feature | Effort | Why |
| --- | --- | --- | --- | --- |
| Confidential Intents | **Maybe, later**, for the withdrawal and residual routes only | F4 (residual, withdrawal) | 2 to 3 days to add the flag to the quote calls and test | Hides the route of a swap, not the destination ([docs](https://docs.intents.aurora.dev/confidential-intents)). Does not hide the obligations in the contract. Operator and verifiability of the private shard are not described |
| OutLayer (FastNEAR off-chain compute in Intel TDX) | **Maybe, for class C only** | F8 class C broker | 10+ days; a real broker with attestation | Runs WASM in a TDX enclave with attestation and keeps secrets decrypted only inside it; the docs call it a third-party service and tell integrators to evaluate its guarantees and key custody before production ([docs](https://docs.near.org/primitives/off-chain-compute/outlayer)). Status (beta or production) and pricing are not stated. Class C is not built |
| NEAR AI Cloud attestation | **Yes, when agents run live inference** | M7 agents (mock mode today) | 2 days to verify the attestation of the inference endpoint in the agent | The docs describe verification of the model (NVIDIA and Intel), the gateway and the TLS binding ([docs](https://docs.near.ai/cloud/verification)). A community claim that the reference verifier does not prove the model is the legitimate one was seen and **not verified**. Needs the account top-up that is still pending |
| Global Contracts | **Not for the hackathon.** Maybe for many circles | M1 deployment | 1 day | Deploy the code once and attach by hash or account; publishing costs 10 NEAR per 100 KB, burned; worth it for about 10 or more accounts ([docs](https://docs.near.org/smart-contracts/global-contracts)). One contract per circle and a handful of circles: regular deployment is cheaper. By hash the code cannot be upgraded; by account the owner can change it at any time |
| Trezu (treasury app) | **No for now.** Optional for the DAO of a circle | F7 | 1 day to test a proposal flow | Secondary sources describe a non-custodial multisig treasury for NEAR DAOs with Sputnik DAO proposals and swaps; its own site did not load, so custody model, fees and status are **not verified**. The DAO scripts of this repository already print the proposal commands |
| NEAR AI Agent Market | **Study only** | M7 | none | See [agents/docs/agent-market.md](../agents/docs/agent-market.md): no documented API, escrow in NEAR, different money |
| Agent Payments Skill | **No** | F2 (buyers) | 3 days to run next to the x207 client | A skill that lets an agent pay x402 services in USDC from assets on 35+ chains through NEAR Intents; today it pays in USDC on Base, Polygon or Arbitrum, with more networks upcoming ([near.org](https://www.near.org/agentic-payments)). It solves cross-chain funding of one payment, not credit between agents. It could fund the stake of a member |
| NEP-413 | **Already used** | all signed formats | done | Final standard for `signMessage`: tag 2^31 + 413, SHA-256, Ed25519, nonce and recipient against replay ([NEP](https://github.com/near/NEPs/blob/master/neps/nep-0413.md)). x207 builds the same payload (ADR-06) and the contract checks it with `env::ed25519_verify`. |
| Alternative indexers | **Yes, a choice is needed** | P8, the indexer (M6) | 2 days | NEAR Lake is deprecated since 24 March 2026 and Neardata (FastNEAR) is named as its replacement as a drop-in replacement; the nearcore Indexer is described as costly to run. Prices, limits and terms of Neardata were **not verified**. The backend already reads blocks from an RPC source and from Neardata; the real risk is the limits of a public provider, which were not measured |

## Notes

- Nothing here was tried in code except NEP-413, the indexer sources and the Sputnik DAO scripts, which the repository already uses.
- Prices and limits of third-party services change; recheck before depending on them.
- Order if time allows: indexer choice, NEAR AI attestation, Confidential Intents flag, then class C.
